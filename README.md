# Scorebook

A lightweight software utility designed to automate the calculation of university Cumulative Weighted Averages (GPA) based on standard credit-hour weighting systems.

## Features
- Accepts user input for course names, credit hours, and letter grades.
- Dynamically calculates current WA/CWA
- Outputs the official graduation class division (e.g., First Class, Second Class Upper).

## Tech Stack
- Built using [HTML/CSS/Javascript]
- Developed using AI-assisted pair programming workflows.
